# Archived report generators

These scripts contain fixed performance figures, case-study predictions, and unsupported claims. They are retained for provenance, not as evidence of completed experiments. Direct execution is disabled so they cannot overwrite measured outputs or create misleading reports.

Use `article_src/src/run_all_experiments.py` to train and evaluate models. The current reviewed paper is in `paper/`. The original paper describes commit `c8ddfeb`; later code fixes do not retroactively validate model results.
